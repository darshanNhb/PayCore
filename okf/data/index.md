# Tables

* [users](tables/users.md) - Represents a logged-in identity and RBAC role.
* [company](tables/company.md) - Top-level tenant container.
* [employee](tables/employee.md) - Represents a physical person working for the company.
* [contract](tables/contract.md) - Employee compensation and schedule terms.
* [working-schedule](tables/working-schedule.md) - Defines working hours for employees.
* [attendance-record](tables/attendance-record.md) - Check-in and check-out logs.
* [time-off-request](tables/time-off-request.md) - Requests for leave by employees.
* [salary-structure](tables/salary-structure.md) - Defines parent structures for payruns.
* [payrun](tables/payrun.md) - Batch payroll processing records.
* [payslip](tables/payslip.md) - Individual employee salary calculation for a payrun.
