# PayCore Knowledge Bundle

PayCore is a comprehensive HR and Payroll Management System designed to simplify the complexities of running a business.

# Subdirectories

* [services](services/index.md) - The core Next.js application and API routes.
* [data](data/index.md) - Database tables and Prisma schema models.
* [scripts](scripts/index.md) - Utility scripts for database seeding and maintenance.
